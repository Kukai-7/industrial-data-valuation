# Industrial Data Valuation: A Research Framework

*Un cadre de recherche pour classer la valeur d'un portefeuille de données industrielles.*

## Research question

How can a portfolio of industrial datasets be valued as an intangible asset in a way that is transparent, reproducible and honest about its uncertainty? The framework scores each dataset on 17 compliance criteria, values it with three approaches (cost, market, income) and turns the result into a **relative ranking** for deciding where to act first, not a price.

## The method in one formula

The reference framework is the data valuation framework of the Horizon Europe project DATAMITE (Vyhmeister et al., 2025):

```
V = QRU × Σ(Val × ICF) / Vp
```

- **QRU**: a quality, relevance or utility score, chosen by the level of analysis. Here it is the quality side: the 17-criterion compliance score (documentation, intrinsic quality, fitness for the model).
- **Val**: the potential value of a dataset. Here it is a confidence-weighted blend of the cost, market and income approaches.
- **ICF**: the information cost fraction, which depends on how the data is used or shared (1 for a one-off transfer, below 1 for a subscription).
- **Vp**: a correction for acquisition and processing time, `Vp = 1 + tp / ta`, close to 1 when processing is light.
- **Σ**: the sum runs over the components of the portfolio (datasets, or uses of one dataset).

Notebook 01 applies the compliance score inside each approach (it adjusts the cost quality factor, the market discount and the income multiplier) rather than as an outer multiplier; notebook 02 and the [online demonstration](https://huggingface.co/spaces/Kukai-7/industrial-data-valuation-demo) apply the formula literally.

## Reproducibility

- Python 3.13; packages in [`requirements.txt`](requirements.txt).
- Fixed seed: `2026` for the Monte Carlo simulation (notebook 01) and for the synthetic data (notebook 02).
- `Run All` is enough: no external data is read, every figure is recomputed from the parameter cells.

```bash
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute notebooks/01_valuation_framework.ipynb --inplace
```

## Known limits

- **Relative values, not a price.** Amounts rank datasets against each other; they are not an opposable price. A price would need an external benchmark.
- **Anonymised case.** The eight datasets of notebook 01 describe an anonymised industrial site; all amounts are working assumptions, consistent with each other, not accounting data.
- **The income leg dominates.** Results depend most on assumptions about future benefits; the sensitivity analysis and the Monte Carlo simulation show by how much.
- **Secondary references to check.** Some regulatory and market figures come from press reports and official statements; they are cited as published and should be checked against the primary texts.
- **Synthetic data.** The Hugging Face tables are invented for illustration and make no claim about real-world processes.
