# Data

`data/synthetic/` receives the three Parquet tables written by `notebooks/02_synthetic_data_generation.ipynb` (`sensors`, `maintenance`, `supply_chain`). They are not versioned in this repository: run the notebook to regenerate them (fixed seed, identical output), or download them from Hugging Face:

https://huggingface.co/datasets/Kukai-7/synthetic-industrial-data-valuation

Synthetic data generated for methodological illustration. No real industrial data.
